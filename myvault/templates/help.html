Quick start — your first 5 minutes

The whole app is built around one idea: you decide what to store, not the other way around. Here's the fastest way to see it work.

  1. Create a category. A category is like a labeled drawer — "Customers", "Domains", "Passwords", anything you like. Click New category on the dashboard, give it a name and an emoji icon, and save.
  2. Add a few fields. Fields are the questions each record in that drawer will answer — a Name, an Email, a Phone number. Open your new category's Edit fields page and add two or three.
  3. Add your first record. Go back to the category and click New record (or use the + Add button in the header from anywhere). Fill in what you know and save.
  4. Open it, edit it, find it. Click the record to see it, Edit to change it, or use the Search box in the header to find it by anything you typed into it.
  5. That's it. Everything else in this app — tags, search, the calendar, cost totals, reminders — is built on top of that same simple loop: categories hold fields, fields hold records.

Getting started & signing in

The very first time anyone opens {{ app_title }}, it asks you to create two separate things — don't mix them up:

  • Your account username & password — this is what you type in every time to sign in, like any other website.
  • The master password — a second, different password that unlocks your encrypted information (things like saved passwords). You won't be asked for it every time, only when {{ app_title }} has been locked (for example, right after the server restarts).

Write your master password down somewhere safe. It is never stored anywhere in the app — not even we can recover it. If it's lost, anything encrypted with it is gone for good.

Once someone has completed that setup, everyone else just signs in with a username and password an admin creates for them (see Users & roles).

Categories

A category is a labeled collection of records — think of it as a filing drawer. You're not limited to what came with the app; you can make a category for absolutely anything: Customers, Domains, Recipes, Passwords, Equipment, whatever fits how you work.

Example: to start tracking customers —

  1. From the dashboard, click New category.
  2. Type a name, e.g. Customers, and pick an icon (try typing an emoji like 👤 into the icon box).
  3. Click Create — you'll land on that category's field builder, ready for the next step (see Fields).

Categories can be renamed, given a new icon, reordered, or deleted at any time from Categories in the top menu (only admins see this). Deleting a category permanently deletes every record inside it — the app will stop you if another category still links to it (see Linked records) until you fix that first.

Fields & field types

A field is one question every record in a category will answer — a category is really just "a name plus a list of fields." Open any category and click Edit fields to add, reorder, or remove them.

Example, continuing Customers: add a Name field (required), an Email field, and a Signed up date field. Each one you add becomes a box on the "new record" form and a column in the list view.

When adding a field you choose its type — this decides what kind of box it shows and how it behaves:

  • Text — a single line of anything (a name, a title).
  • Text area — a bigger box for notes or descriptions. Has a small toolbar for bold, italic, headings and lists.
  • Password (encrypted) — for anything sensitive (an actual password, an account number). It's stored scrambled and only shown again if you click Reveal while unlocked. See Passwords & unlocking.
  • URL — a web address; shown as a clickable link.
  • Email — shown as a clickable "email this person" link.
  • Number — plain numbers, sorted numerically not alphabetically.
  • Cost (recurring) — a number that's also billed monthly, yearly, or once — feeds the Costs dashboard.
  • Date — a plain date. Shows up on the Calendar.
  • Expiry / reminder date — a date that also warns you as it approaches. See Expiry & reminder alerts.
  • Dropdown (single-select) — pick one option from a list you define (e.g. Status: New / Active / Closed).
  • Multi-select — like a dropdown, but pick several at once.
  • Linked record — points at one record in another category. See Linked records.
  • Checkbox — a simple yes/no.
  • Code (monospace) — for pasting a snippet, key, or command, shown in a fixed-width font.
  • File (image or document) — attach one photo or document per record. See File attachments.

Tick Required on a field to stop a record being saved without it. A field's machine name (used internally) is fixed once created, but its label, type, and settings can be changed later from Edit next to it — including turning a plain field into an encrypted one, which scrambles every existing value for you in one step (you'll need {{ app_title }} unlocked to do that).

Removing a field hides it everywhere but keeps the data underneath, in case you add it back or need to recover it from the raw database.

Adding, editing & deleting records

A record is one entry in a category — one customer, one domain, one password. Open a category and click New record to add one; the form shows exactly the fields that category has.

From a category's list, or from a record's own page, you'll see:

  • Open — view the full record.
  • Edit — change any of its fields.
  • Clone — make an exact copy as a new record (handy for near-identical entries, e.g. a new subscription similar to an old one). Any attached file is copied too, as its own independent file.
  • Delete — moves the record to Trash, it isn't gone yet.

Every record also has a Tags box on its edit form — see Cross-category tags — and shows a "Last updated" date and a Referenced by section listing any other records that point at it (see Linked records).

The quick-add button

The blue + Add button in the header — visible on every page — opens a small list of every category you have. Click one to jump straight to its "new record" form, without navigating there first.

Linked records

A Linked record field points one record at exactly one record in another category — the way a spreadsheet might reference a row in a different sheet. It's the right tool when the relationship is fixed and structural.

Example: if you also have a Projects category, give it a "Client" field of type Linked record, targeting Customers. Now every project picks one customer from a dropdown, shows a clickable link to them, and that customer's own page lists every project linked to them under Referenced by.

A category that other records still link to can't be deleted until those links are removed or pointed elsewhere — this stops you accidentally breaking a relationship you didn't realize existed.

Cross-category tags

Tags solve a different problem than linked records: grouping things that aren't in a fixed relationship, on the spot, across any categories at all — no setup required.

Example: you're renewing a domain and its hosting plan at the same time, even though "Domains" and "Hosting" are unrelated categories. Open each record's Edit page and type Q4 renewal into the Tags box (comma-separate if you want more than one tag). Now click Tags in the top menu — you'll see "Q4 renewal" listed, and clicking it shows both records together, grouped by category.

Editing a record's tags replaces the old set rather than adding to it, so typing just office and saving removes any other tags that record had.

File attachments

A File field lets you attach one photo or document to a record — a scanned ID, a contract, a screenshot. Images show a small preview right on the record; anything else downloads when clicked.

Files are encrypted the same way passwords are — you need {{ app_title }} unlocked to view or download one. Uploading a new file replaces the old one automatically; there's also a checkbox to remove it without replacing.

Passwords & unlocking

Anything stored in a Password (encrypted) field (or an attached file) is scrambled before it's saved. You'll always see it masked as dots — clicking Reveal decrypts it just for that moment, and only while {{ app_title }} is unlocked.

The padlock icon in the top-right of every page shows the current lock state:

  • 🔓 Unlocked — encrypted values can be revealed or downloaded. Click it to lock it again yourself.
  • 🔒 Locked — encrypted content stays hidden, even from someone signed into your account, until the master password is entered again. This happens automatically whenever the server restarts.

Locking doesn't sign you out or hide anything else — categories, plain fields, and everything non-sensitive stay fully visible and editable either way.

Trash — undoing a delete

Deleting a record never erases it right away — it moves to Trash (in the top menu), where it sits until you either:

  • Restore it — brings it back exactly as it was, everywhere (lists, search, tags, links all see it again).
  • Delete forever — this one really is permanent. There's no second trash after this.

A trashed record disappears from search results, category lists, and linked-record dropdowns until it's restored — so it won't clutter anything while it's waiting there.

Backup & restore (admin only)

Everything you've stored — every category, field, record, encrypted password and attached file — lives in one single file. Settings → Backup & restore lets an admin:

  • Download a backup — a safe, consistent snapshot you can take any time, even while others are using {{ app_title }}. Keep it somewhere safe (a USB drive, cloud storage you trust).
  • Restore from a backup — replaces everything currently stored with the contents of a file you upload. Type RESTORE to confirm — this is the one action in the whole app that can wipe out today's data, so it's deliberately hard to do by accident. Your current database is saved automatically first, just in case.

Search

The search box in the header looks across every category at once, matching anything you've typed into a plain field, a linked record's name, a filename, or a tag. Encrypted (password) values are never searchable, by design.

Sort & filter

On any category's record list, click a column heading to sort by it — click again to reverse the order. The Filter bar above the table narrows the list down further: type a few letters for a text field, or pick a value from a dropdown for choice-type fields. Both sort and filter show up in the page's address, so you can bookmark or share a particular view.

Expiry & reminder alerts

An Expiry / reminder date field is a normal date that also watches itself — once it's within its configured window (set when the field was created, e.g. "30 days before"), it shows up as a warning badge in the header on every page, for every user.

Click the badge to see exactly what's due, when, and to Dismiss one you've already dealt with — it'll quietly reappear if the date changes, or if it becomes more urgent (an upcoming reminder you dismissed will still alert you once it's actually overdue).

Calendar view

The Calendar page plots every Date and Expiry / reminder date field, from every category, onto a normal month grid — a domain's expiry, an invoice due date, a meeting, all on the day they actually fall, color-coded by category. It's read-only: click any date to open that record and make changes there.

Costs dashboard

If you use any Cost (recurring) fields (see Fields), the Costs page adds every one of them up into a single monthly and annual total — automatically converting a yearly cost into its monthly equivalent and vice versa, with a per-category breakdown underneath so you can see what's driving the number.

The dashboard summary

The dashboard (your home page) leads with up to three cards, each only shown when there's something to say: your nearest upcoming alerts, your cost totals, and — for admins — the most recent activity. Below that is the usual grid of your categories.

Activity log (admin only)

Settings → Activity log is a running history of who did what and when — who created, edited, trashed, restored, permanently deleted, or cloned a record, and who created or deleted a category. It's the answer to "wait, who deleted this?" — and it keeps its own record even after the thing it describes is long gone.

Templates (admin only)

A template is just a category's field list, saved as a small file — no records included. Export template (on a category's field page) downloads one; Import (on the Categories page) creates a brand-new, empty category from one. Handy for recreating the same category shape somewhere else, or sharing a layout with someone.

Users & roles (admin only)

Everyone who can sign in sees the same data — there's no per-category privacy between users. The difference is what they can restructure:

  • Member — can add, edit, trash and clone records freely, but can't create/edit/delete categories or fields, manage other users, or use backup/restore.
  • Admin — can do everything, including all of the above.

Manage this from Settings: create a user, reset a password, change a role, or remove someone (their past records are kept, just no longer credited to their account).

Common questions

I forgot my master password — can you reset it?
No one can, including an admin. It's never stored anywhere, by design. Anything encrypted with it (passwords, files) is unrecoverable. Everything else is unaffected and stays fully usable.
I deleted something by mistake.
Check Trash first — unless it was already permanently deleted from there, it's recoverable with one click.
Why can't I see a "New category" or "Settings" option?
Those are admin-only. Ask whoever set up your account to either do it for you or make you an admin (see Users & roles).
Why does it say "Locked"?
This happens automatically after the server restarts, as a safety measure. Click the padlock and enter the master password to unlock — see Passwords & unlocking.
Can two people edit at the same time?
Yes — every signed-in user shares the same live data.
Is my data sent anywhere else?
No. {{ app_title }} makes no outbound calls of any kind and has no analytics or telemetry — everything stays on the server you're running it on.
